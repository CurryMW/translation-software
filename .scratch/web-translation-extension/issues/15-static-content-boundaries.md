# 15 — 遵守静态网页内容边界

**What to build:** 用户在普通静态页面开启翻译时，扩展能够识别完整的标题、正文、列表项、帖子、评论、图片说明和引用，同时安全排除链接、导航、按钮、代码、表单、编辑区、隐藏内容和重复嵌套文本，只为真实阅读内容显示译文。

**Blocked by:** 14 — 用 Fake 翻译一个可视文本内容块

**Status:** ready-for-agent

**用户变更（2026-09-25）：** 产品目标改为“只要是可读英文就可以翻译”，因此导航、链接、按钮、侧栏和账号标签不再作为默认排除项；表单输入、代码、扩展自身 DOM、图片/视频画面仍保持安全排除。

- [ ] 本地聚焦夹具覆盖所有默认纳入的文本内容块类型，并从用户可见结果验证其各自只生成一个译文。
- [ ] 导航、工具栏、按钮、菜单、页脚、广告、代码、表单、可编辑区域和扩展自身 DOM 均不产生翻译任务。
- [ ] 所有链接文字一律排除；完全由链接构成，或去除链接后不再构成完整独立语义的候选块整体跳过。
- [ ] `aria-hidden`、折叠、不可见样式和视口外内容不会提交给 Fake Adapter。
- [ ] 父子候选文本重叠时只选择最小且完整的文本内容块，不出现父块与子块双重译文。
- [ ] 纯数字、纯标点和纯 emoji 自动跳过；正常外语短语不会因为过短而跳过。
- [ ] 当前页面内以节点身份和规范化原文识别重复候选，重复扫描不会重复发送或插入。
- [ ] 自动测试通过内容发现行为接缝断言“产生哪些文本内容块”和“哪些被安全跳过”，不直接测试私有选择器函数。
- [ ] 固定排除语料不会被写入日志、快照或测试失败输出。
