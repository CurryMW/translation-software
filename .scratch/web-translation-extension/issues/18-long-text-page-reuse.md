# 18 — 安全翻译长文本并复用页面结果

**What to build:** 用户阅读超出供应商单次安全长度的内容时，扩展按段落和句子拆分、按原顺序合并完整译文；同一页面中的完全相同请求可以复用成功结果，但刷新、语言变化或原文变化后不会误用旧译文。

**Blocked by:** 17 — 在套餐和字符预算内调度可视翻译

**Status:** implemented-local（verify 与双轴复审已通过；未提交）

- [x] 长文本先按段落、再按句子拆分，每个请求片段不超过所选套餐的安全长度。
- [x] 多片段响应无论返回顺序如何，都按原文片段顺序合并并保留段落边界。
- [x] 无法在安全长度内继续拆分的单段返回明确失败，不截断、不漏译也不发送超限请求。
- [x] 页面内仅以规范化原文、源语言、目标语言和供应商版本完全一致的成功结果复用译文。
- [x] 失败结果不缓存；原文、语言或供应商版本变化时不复用旧结果。
- [x] 刷新、页面导航或浏览器重启后页面内复用状态清空。
- [x] 原文、译文、拆分请求和合并结果均不持久写入扩展存储或诊断日志。
- [x] 固定长文本、换行、特殊字符和乱序响应测试使用人工写定结果，不由被测拆分算法生成预期。
- [x] 页面呈现的最终译文没有重复片段、顺序错误或静默截断。

## 本地实施证据（2026-09-10）

- 调度器以父任务 identity 管理内部片段；每次实际 adapter 提交均重新执行套餐长度、QPS/并发、预算、授权与预检，取消父任务会阻止尚未提交片段。
- 页面缓存仅驻留 service worker 内存，以 Chrome `documentId`、段落拓扑规范化原文、语言及 adapter id/version 隔离；导航、tab 关闭、documentId 更换和缺失 documentId 均不会复用或保留页面结果。
- 本地真实 dist 闭环覆盖 content → handler → scheduler → Shadow UI：长段落最终为单一容器、三片 Fake 结果且保留 `\n\n` 段落边界。
- 验证：`npm run verify` 通过（Vitest 123/123，Playwright 2/2）；Spec 与 Standards 最终复审清零。未访问真实百度，未持久化或日志输出原文、译文、完整 URL 或凭据；未提交。
