# 16 — 按网站切换目标语言并纠正源语言

**What to build:** 用户可以为每个网站选择并记忆目标语言，通常依靠自动源语言识别；识别不确定或错误时，可以对单个文本内容块手动指定源语言并重试，而同语言和不满足混合语言阈值的内容不会浪费调用。

**Blocked by:** 15 — 遵守静态网页内容边界

**Status:** implemented-local (Fake contract; real Baidu account/direction validation deferred to #24)

- [x] 新网站默认目标语言为简体中文，目标语言选择按域名持久保存且不影响其他网站。
- [x] 设置页或 popup 只展示百度适配器当前已验证支持的语言方向，不展示未实现供应商。
- [x] 源语言默认自动识别；确认与目标语言相同时跳过且不产生翻译请求。
- [x] 无法可靠识别时显示手动翻译入口，不反复自动请求。
- [x] 用户可以对单个文本内容块指定源语言后重试，其他文本块的自动识别设置不受影响。
- [x] 中英混合等内容按“非目标语言约占30%或以上”的启发式规则决定是否自动翻译，并通过固定语料校准；不得以拉丁字母数量代替语言识别。
- [x] 切换网站目标语言会使当前标签页旧译文失效、移除旧展示并重新处理当前可视内容；其他标签页不批量翻译。
- [x] 固定测试覆盖英语、中英混合、日语、韩语、西班牙语、同目标语言和无法判断的输入。
- [x] 语言改变后的旧响应不能显示为新目标语言结果。
