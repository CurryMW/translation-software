# 确定语言检测与目标语言策略

Type: grilling
Status: resolved
Assignee: Curry学长（Codex 协作）
Blocked by: 01

## Question

确定语言策略：自动检测与手动源语言选择如何共存，目标语言如何切换和记忆，简体中文默认值是否按 Chrome 语言覆盖，混合语言/中文比例/专有名词/emoji/极短文本何时跳过，以及检测失败时的用户提示。

## Comments

已确认的前提：自动识别源语言；目标语言默认简体中文，可切换；纯数字、纯标点、纯 emoji 跳过，正常短文本不按长度硬过滤；混合文本采用约 30% 非目标语言占比的初步策略。

待用户确认的建议（不是最终决定）：

1. 目标语言按网站域名记忆，不跟随 Chrome 语言变化；选项仅列出当前供应商确实支持的语言。
2. 改变目标语言时，当前标签页移除旧译文并重译可见内容；屏外内容进入视口后再处理；其他已打开标签页先不主动批量重译，刷新后使用新设置。
3. 保留自动检测，并允许对当前文本块手动指定源语言后重试；确认原文已是目标语言时跳过，不重复显示同语言译文；无法确定时提供单块翻译入口，不反复自动请求。
4. 30% 占比仅作为混合内容的待验证启发式，不以英文字母数量冒充精确语言判定；不支持的语言明确提示，不偷偷换目标语言。供应商语言支持与检测能力必须在正式实现前核验。

技术澄清：语言不等于字符类别，例如英文和法文均使用拉丁字母；此前 30% 提议并不足以定义适用于所有目标语言的识别算法，其具体实现仍待验证。

## Answer

用户对本轮三个建议明确回复“是”，确认以下产品行为：

1. **按网站记忆目标语言**：目标语言设置按网站域名保存，网站间互不影响；新网站沿用此前确认的简体中文默认值。
2. **切换后的翻译范围**：当前标签页移除旧译文、重新翻译可见内容；屏外处理时机以 [动态网页契约的最新反馈](05-dynamic-processing.md#最新用户反馈) 为准，原“到附近”预译范围已被用户收紧；其他标签页不立即批量重译，避免额外调用。
3. **识别异常时的处理**：保留自动识别，允许单块手动指定源语言后重试；确认已是目标语言的内容跳过；无法判断时提供手动翻译入口，不反复自动请求。

纯数字、纯标点、纯 emoji 及短文本的规则仍以 [内容边界决策](02-content-boundary.md) 为准。

本票据关闭代表产品行为已决定，不代表语言识别算法已验证。混合文本约 30% 的规则仍待样本验证，不能以拉丁字母数量替代语言识别；具体供应商的语言清单与检测能力也尚需核验。其他标签页后续何时读取新设置及切换时的旧请求隔离，由动态处理票据落实。
