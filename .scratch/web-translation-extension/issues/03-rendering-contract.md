Type: prototype
Status: resolved
Assignee: Curry学长（Codex 协作）

## Question

原文保留、译文显示在下方的交互契约是什么？需要确定译文容器的视觉层级、加载中状态、失败与重试、折叠/隐藏、样式隔离、布局变化、无障碍语义，以及在长帖和重复渲染场景下用户能看到的稳定行为。用一个低保真页面原型让用户确认。

## Answer

用户查看原型后明确选择 A「紧凑双语」。以下为选中方案的呈现契约，不表示正式扩展已实现或跨网站兼容性已验证：

- 保留原文，在对应内容块下方插入译文，位于原网页操作区之前；不使用悬浮气泡或替换原文。
- 译文默认展开，轻量语言标签与“收起译文”操作置于同一行；不采用 B 的独立卡片或 C 的默认折叠。
- 加载时显示简短状态；失败不影响原文，提供单块重试入口。原型的“模拟完成”按钮不是正式产品功能。
- 收起仅隐藏译文内容，保留展开入口，不发起额外翻译请求。
- 关闭网站翻译开关时移除译文展示，保留原文。
- 长译文自然撑高页面，不覆盖原文；保持原有段落分隔。
- 正式实现需保留可用的明暗背景对比度、键盘操作、展开状态语义；不得向宿主网页泄漏全局样式。
- 重复渲染、异步回写、取消与焦点稳定性属于正式实现验证范围，原型的整列表重建不可直接用于扩展；动态处理细节继续由“确定动态网页的增量翻译契约”票据决定。
