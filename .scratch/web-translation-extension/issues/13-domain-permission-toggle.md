# 13 — 按域名授权并记忆页面翻译开关

**What to build:** 用户可以从 popup 为当前 `http/https` 网站明确授予或拒绝访问权限，开启或关闭该域名的页面翻译，并在重新打开页面或浏览器后看到一致的网站设置；此时仍不发送任何真实翻译请求。

**Blocked by:** 12 — 加载安全的 React MV3 扩展骨架

**Status:** ready-for-agent

- [ ] popup 能区分可授权的普通网页、尚未授权的网站、已授权网站和 Chrome 内部等不支持页面。
- [ ] 首次开启网站翻译必须由用户操作触发对应域名的可选主机权限请求，安装时不提前索取所有网站权限。
- [ ] 用户拒绝权限后，页面不注入翻译功能、不扫描正文、不发送消息载荷，并显示可理解的未授权状态。
- [ ] 权限允许后，页面翻译开关按域名保存；其他域名保持独立状态。
- [ ] 新域名使用简体中文作为默认目标语言，并为后续切换保留网站级设置。
- [ ] 关闭页面翻译开关会通知当前页面停止扩展会话，但不会改动宿主原文。
- [ ] Chrome 中撤销网站权限后，popup 和页面状态能够恢复为未授权，不继续依赖旧设置扫描页面。
- [ ] 本地浏览器闭环测试覆盖允许、拒绝、关闭、重新打开和不支持页面，且全程使用 Fake/无供应商请求模式。
