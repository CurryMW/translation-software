# 确定翻译失败与调用成本控制策略

Type: grilling
Status: resolved
Assignee: Curry学长（Codex 协作）
Blocked by: 01, 03

## Question

确定失败与成本控制策略：网络错误、配额耗尽、鉴权失败、内容过长、服务限流分别如何呈现；单块重试是否有退避；是否允许取消/暂停；是否做会话级缓存；如何避免页面自动扫描造成意外高额调用。

## Comments

### 本轮建议

1. **本地字符预算**：设置页让用户选择百度套餐，并把当前官方免费字符数作为可编辑的本地月度上限；默认在本地估算达到上限时暂停自动翻译，用户可明确调整后继续。该计数只覆盖此扩展发出的原文字符，不代表百度账户账单，也不能发现其他程序使用同一凭据的调用。
2. **分类重试**：网络中断、超时和临时服务异常最多自动重试 2 次，逐次延长等待；限流进入队列等待，不让所有文本块同时重试。鉴权/签名错误、余额或配额耗尽、不支持的语言方向、内容风险与无效参数不自动重试，给出可执行提示；用户仍可在单块上手动重试。
3. **长文本切分**：请求发出前按段落、再按句子切分到当前套餐的安全长度内，按顺序合并译文。无法安全切分的单段标记失败，不截断原文、不偷偷漏译。
4. **仅页面内复用**：同一页面内，相同规范化原文、源/目标语言和供应商结果可用内存复用；刷新、导航或浏览器重启后清空，不持久保存原文和译文。切换语言、原文更新或失败结果不复用。
5. **取消与总故障**：关闭翻译、离开标签页或拒绝切入确认后不再提交等待任务。凭据无效、配额耗尽或服务关闭属于供应商级故障：暂停整页队列并只显示一条顶部提示，文本块保留可恢复状态，避免每块重复报错。

未决定的技术参数（请求超时、退避秒数、切分安全长度和并发数）由实现按所选百度套餐设保守默认，并在验收中测量；不能把本地预算称为百度官方用量或“绝不扣费”保证。

以上待用户确认后才写入 Answer；当前票据不代表功能已经实现。

## Answer

用户确认采用本轮建议：扩展以可编辑的本地月度字符预算限制自动调用；仅对网络、超时和临时服务异常最多自动重试 2 次，限流请求进入队列，确定性错误不自动重试；长文本按段落和句子安全切分后顺序合并；译文只在当前页面内存中复用；关闭翻译、离开标签页或拒绝切入确认后停止提交等待任务，供应商级故障暂停整页队列并合并为一条顶部提示。

实现时必须把本地计数明确标为“本扩展估算”，不能把它表述为百度账户的官方用量或零费用保证。超时、退避、长度与并发采用保守默认，并在 MVP 验收阶段通过实测校准。
