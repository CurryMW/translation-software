# 17 — 在套餐和字符预算内调度可视翻译

**What to build:** 用户滚动和阅读页面时，扩展只为仍处于实际视口中的文本内容块排队，并按照所选百度套餐的速率和可编辑本地字符预算提交任务；滑出视口、取消或达到预算时不会产生新的供应商调用。

**Blocked by:** 16 — 按网站切换目标语言并纠正源语言

**Status:** implemented-local（verify 与双轴复审已通过；未提交）

- [x] 翻译任务进入队列前和实际提交前都重新检查页面会话、用户授权、节点身份和当前可见性。
- [x] 尚未发送就滑出视口的任务从等待队列移除，滚回后可以按需重新排队。
- [x] 调度器可以按套餐配置并发和速率；标准版路径严格按 QPS 1 串行，不能使用高级版默认值。
- [x] 设置页允许用户选择套餐并调整本地月度字符预算，清楚标注为“本扩展估算”。
- [x] 本地预算按实际提交的源字符累计，重试产生的新提交也计入估算；达到上限后停止自动提交并给出可执行提示。
- [x] 月度预算周期和时钟可被测试控制，跨周期后计数按明确规则开始新周期。
- [x] 本地预算不被描述为百度官方账单、账户总用量或零费用保证。
- [x] 关闭会话、撤销授权或取消等待任务后，调度器不再提交相关任务。
- [x] 自动测试观察提交结果、预算和用户状态，不断言内部队列数据结构或内部调用顺序。

## 本地实施证据（2026-09-10）

- `translation-usage-controller` 在 trusted service worker 存储中仅持久化套餐、UTC `YYYY-MM` 周期和已提交源字符数；默认标准版。可注入时钟，跨周期自动清零；并发预留串行化，取消保留仅回滚同一周期。
- `translation-scheduler` 在入队和 adapter 提交前均重验授权与会话；以 tab/frame/request 作用域隔离取消，预检与取消消息只携带任务标识。标准版实测提交起点间隔至少 1000ms；高级版显式按其限额，不是默认值。
- 内容脚本在 scroll/resize 后移除屏外等待任务并发送无正文取消；预检只接受节点身份、规范化原文及当前可见性仍匹配的活动块。预算耗尽显示设置页可执行提示。
- 设置页允许选择标准/高级套餐和编辑非负本地月度字符预算，并明确说明“本扩展估算”，非百度官方账单、账户总用量或免费保证；周期文案明确为 UTC 月度周期。
- 验证：`npm run verify` 通过（TypeScript、production build、Vitest 114/114、真实 dist 本地 Fake E2E 2/2）；Standards/Spec 双轴复审均清零。所有测试为本地夹具/Fake；未访问真实百度，未记录正文、完整 URL、凭据或请求/响应体。
