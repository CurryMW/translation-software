# 22 — 标签页切入确认并暂停后台调用

**What to build:** 用户每次切入已开启翻译的网站标签页时，都先在页面内决定本次停留是否继续翻译；未确认、拒绝、离开标签页或关闭网站翻译后，扩展不会提交新的自动任务，同时按既定规则保留或移除已有译文。

**Blocked by:** 21 — 原文变化后拒绝过期译文

**Status:** implemented-local

- [x] 每次标签页由后台变为当前可见且该域名翻译开关已开启时，显示非阻塞的切入翻译确认。
- [x] 确认前不提交新的自动翻译任务；关闭提示不视为同意。
- [x] 用户确认后才开始本次停留的可视内容翻译，并继续遵守预算、速率和错误规则。
- [x] 用户选择“暂不翻译”时保留已有译文但不新增请求；下次重新切入仍再次询问。
- [x] 标签页进入后台后停止提交新的自动任务；已经发出的供应商请求不承诺撤销费用，但只有会话仍有效的结果可以写回。
- [x] 未开启翻译的网站不显示切入确认，也不建立翻译会话。
- [x] 关闭网站翻译开关会清除等待任务和扩展译文 UI，宿主原文保持不变。
- [x] 多标签页测试证明不同标签页的确认、语言和任务版本彼此隔离，不会串页写回。
- [x] 切入提示支持键盘、可见焦点、清晰的确认/拒绝语义及浅色/深色背景。

本地验证：`npm run verify` 通过 TypeScript、production 构建、Vitest 199/199 与 Playwright 2/2。真实 dist E2E 仅使用 Fake Adapter 与 `127.0.0.1`，以数值用量证明确认前、后台新增与拒绝后的零提交；未访问真实翻译服务，未创建 Git 提交或远程写入。
