# 20 — 翻译滚动与异步新增的可视内容

**What to build:** 用户在动态信息流中滚动或页面异步插入内容时，新进入实际视口的文本内容块会自动使用既有语言、预算和失败规则翻译；视口外内容不预译，页面静止后也不会持续扫描或产生请求。

**Blocked by:** 18 — 安全翻译长文本并复用页面结果; 19 — 以可恢复状态处理供应商故障

**Status:** implemented-local

- [x] 本地动态信息流夹具可以持续追加、移除和复用 DOM 内容块，并从用户可见结果验证增量翻译。
- [x] 只有实际进入视口的新增文本内容块排队，不翻译视口附近或屏外内容。
- [x] 虚拟列表滚动时，节点复用和重复观察不会造成译文错位或多个译文容器。
- [x] 扩展自身插入的 React DOM 不会触发新的内容发现或形成观察循环。
- [x] 页面无 DOM 变化且停止滚动后，不继续执行无意义扫描或产生新请求。
- [x] 单次可视区域扫描耗时、请求数、队列深度和 DOM 插入数能够被脱敏采样。
- [x] 动态夹具的扫描 P95 目标不超过100毫秒，超出时测试报告显示可定位的性能证据。
- [x] 连续自动滚动场景没有重复译文、失控请求或无限 Mutation 循环。
- [x] Playwright 使用真实构建产物验证滚动、可见性和动态 DOM，不用 jsdom 结论代替真实布局。
