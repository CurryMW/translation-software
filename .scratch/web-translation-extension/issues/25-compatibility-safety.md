# 25 — 对高风险网站执行兼容性暂停和安全降级

**What to build:** 用户访问扩展无法安全处理的网页时，扩展会跳过不确定内容、回退导致页面破坏的 UI，并对已知高风险域名实施不可绕过的兼容性暂停；维护者可以独立添加、关闭和复查必要站点特例，而不污染通用扫描规则。

**Blocked by:** 22 — 标签页切入确认并暂停后台调用; 23 — 支持开放 Shadow DOM 和获准 iframe

**Status:** implemented-local

- [x] 无法确认候选是否为安全阅读内容时不发送请求；整页无法安全识别时暂停本页新增翻译并显示一条非阻塞提示。
- [x] 检测到扩展造成布局、按钮或滚动等宿主功能异常时，移除当前页扩展 UI、取消等待任务并暂停页面会话。
- [x] 稳定确认存在隐私、页面破坏或费用风险的域名可以进入持久兼容性暂停，跨会话阻止新增请求。
- [x] 高风险兼容性暂停在对应修复通过回归前不能由用户强制绕过，其他网站不受影响。
- [x] 站点特例存放在独立注册表中，并记录域名、可靠触发条件、原因、合成夹具、安全回退和复查触发条件。
- [x] 站点特例失效时，只有通用安全检查独立通过才回到通用策略；否则跳过或暂停受影响范围。
- [x] 随扩展提供完整已知限制清单；运行时仅在命中相关场景时显示简短可执行提示。
- [x] 兼容性诊断只保留当前会话脱敏计数和错误类别，不上传或持久保存正文、账号、完整 URL 或真实页面截图。
- [x] 测试覆盖块级跳过、页面级回退、域名暂停、特例启用/失效和无关网站不受影响。
