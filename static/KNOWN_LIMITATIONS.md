# 已知限制与安全边界

这是网页翻译扩展当前版本随附的限制清单。它描述安全行为，不代表普通缺陷可以通过标记“不支持”跳过。

- 关闭 Shadow DOM、Canvas/图片文字、浏览器内置 PDF、Chrome 内部页和无权限 iframe 不读取、不注入、不发送正文。
- 无法确认是安全阅读内容的块会被跳过；整页无法安全识别时暂停本页新增翻译。
- 检测到扩展 UI 造成布局、滚动或交互异常时，扩展移除自己的 UI、取消等待任务并暂停当前页面会话。
- 被维护者确认存在隐私、页面破坏或费用失控风险的域名会进入本地兼容性暂停；暂停跨会话生效，用户不能强制绕过。
- 站点特例只在独立注册表中维护。特例触发条件失效时，通用安全检查通过才回到通用策略，否则安全跳过。
- 诊断仅在当前页面会话保存脱敏计数和错误类别；不保存或上传正文、译文、账号、完整 URL、截图、请求体或凭据。
- 兼容性暂停和站点特例需要在目标网站结构变更、Chrome 主版本升级或通用扫描器变更后复查。
